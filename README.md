# intern-day-2-frontend

> 第 2 天练习项目，作者：黎剑婷

登录练习项目的前端：React + TypeScript + Vite，对接后端登录接口与待办清单。

## 功能范围

- 登录页：账号密码输入、必填校验、提交中禁用按钮
- 登录后：显示当前用户、待办清单增删改
- 退出登录：清空本地状态并返回登录页

## 技术栈

| 项 | 选择 | 说明 |
| --- | --- | --- |
| 构建 | Vite 7 | 启动快，热更新即时 |
| 框架 | React 19 + TypeScript（strict） | `pnpm build` 里包含 `tsc --noEmit`，类型错误会挡住构建 |
| 路由 | react-router-dom 7 | 两个页面：`/login`、`/` |
| 请求 | 原生 fetch | 只在 `src/api.ts` 里封装一次，不引第三方库 |
| 依赖管理 | pnpm 11.25.0（写死在 `packageManager`） | 锁文件已提交 |

## 登录流程

1. 打开 `/login`，输入账号密码
2. 前端提交到后端 `/auth/login`
3. 后端校验通过后返回访问令牌，前端保存到 `localStorage`（键名 `intern-day-2.token`）
4. 跳转到功能页 `/`，调 `/auth/me` 确认身份
5. 拉取 `/todos` 显示我的待办
6. 点退出 → 调 `/auth/logout` → 回到 `/login`

**刷新页面时**状态是 `checking`，必须先调 `/auth/me` 让后端确认，不凭本地令牌直接放行。任何接口返回 401 都会派发全局事件 → 清空本地状态 → 回登录页。

## 目录结构

```
src/
  api.ts              请求封装：拼地址、带 Bearer、错误翻译成中文
  types.ts            接口数据类型
  auth.tsx            登录态 Context：checking / 已登录 / 未登录
  App.tsx             路由与路由保护
  main.tsx            挂载入口
  styles.css          全部样式（无 UI 框架）
  pages/LoginPage.tsx 登录页
  pages/TodoPage.tsx  待办页（骨架屏 / 空状态 / 失败重试）
```

## 运行

后端要先起来（默认 <http://localhost:8000>）：

```bash
pnpm install
pnpm dev
```

打开 <http://localhost:5173>，用 `alice` / `Passw0rd!2027` 登录。

后端地址通过环境变量覆盖（默认已经是 `http://localhost:8000`）：

```bash
cp .env.example .env
# 改 VITE_API_BASE_URL
```

> 注意：这个地址是**浏览器**访问后端的地址，不是容器内的地址，所以写 `localhost` 而不是容器名。

## 已知问题与限制

- 令牌存在 `localStorage`，XSS 场景下有被读取的风险；生产项目应改存 `HttpOnly` Cookie 并配 CSRF 防护。
- 没有做刷新令牌，令牌过期（默认 8 小时）就要重新登录。
- 只做了两个页面，没有注册、改密码、找回密码。
- 开发环境用 Vite 服务器，不是生产静态托管方案（生产应 `pnpm build` 后交给 Nginx）。
- 部分命令必须绑定 `0.0.0.0` 才能在容器外访问，`package.json` 的 `dev` 脚本已带上。
